# Edunovaa Customer Service Management Dashboard

A responsive frontend dashboard for managing customers, services, and service requests.

This project was developed as part of the Edunovaa frontend training assignment.

---

## Day 1 – Core Application

Day 1 focused on building the basic application structure and core functionality.

### Features

- Login screen with basic validation
- Dashboard with summary cards
- Recent service requests table
- Customer management
- Customer search
- Customer status filtering
- Add customer functionality
- Customer details modal
- Service requests view
- Client-side authentication state
- Protected routes
- LocalStorage-based customer persistence
- Responsive dashboard layout
- React Router navigation

---

## Day 2 – Interactions & UI Improvements

Day 2 focused on improving the Day-1 application with interactive features, reusable components, UI states, and better responsive behavior.

### Dashboard Improvements

- Today / This Week / This Month filters
- Dynamic mock dashboard metrics
- Service request search
- Service request status filtering
- Sorting by date
- Sorting by customer name
- Empty state when no results are found

### Customer Improvements

- Customer search
- Customer status filtering
- Add customer form/modal
- Name, email, phone, service and status fields
- Basic form validation
- Saving/loading state
- Successful form submission state
- Customer details modal
- Customer data persistence using LocalStorage

### UI & Reusable Components

- Reusable Sidebar
- Reusable Header
- Reusable Summary Cards
- Customer Modal
- Status Badge
- Reusable UI elements
- Validation error states
- Empty/no-search-results states

### Responsive Improvements

- Collapsible sidebar on smaller screens
- Responsive navigation
- Mobile-friendly layout
- Horizontal scrolling for wide tables
