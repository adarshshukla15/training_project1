# Edunovaa Customer Service Management Dashboard

A frontend dashboard for managing customers, services, and service requests.

This project was developed as part of a Day-1 frontend assignment. It focuses on building the core application structure, navigation, customer management, and basic client-side data persistence.

## Features

- Login screen with basic validation
- Dashboard with summary cards
- Recent service requests table
- Customer management
- Customer search
- Customer status filtering
- Add customer functionality
- Customer details modal
- Service requests view
- Client-side authentication state
- LocalStorage-based customer persistence
- Responsive dashboard layout

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Browser LocalStorage
